# Campus Safety & Crowd Analytics System 📹

A real-time foot-traffic analysis and crowd-monitoring system designed for spatial density analysis and enhanced campus safety.

### 🚀 Tech Stack
* **AI & Computer Vision:** YOLOv8, OpenCV, MediaPipe
* **Language:** Python
* **Core Concepts:** Real-Time Data Processing, Object Tracking

### ⚙️ System Architecture & Features
* Architected a real-time foot-traffic analysis system for spatial density analysis.
* Integrated YOLOv8 for accurate person detection and live heatmap generation to visualize crowd density.
* Optimized model-processing pipelines to ensure smooth and efficient live video-stream processing.
